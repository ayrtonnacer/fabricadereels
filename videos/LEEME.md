# Videos
Un video = una carpeta = un proyecto HyperFrames. Se crea con `bash engine/nuevo.sh AAAA-MM-tema` (copia `_plantilla/`). Las salidas (`out/`, `audio/`, `final.mp4`) no se suben: se regeneran con los comandos de `CLAUDE.md`. Las copias livianas de los terminados están en `docs/referencias/propios/`.

| Carpeta | Qué es | Estado |
|---|---|---|
| `_plantilla/` | Punto de partida (estética Scale por defecto) | base |
| `2026-11-tensores-scale-oscuro/` | **Qué es un tensor**, versión con estética Scale (la que Ayrton eligió) | ✓ **publicado** en Instagram (2026-11-14); feedback en `docs/PUBLICO.md` |
| `2026-11-tensores/` | Qué es un tensor v5.2, estética línea roja | versión previa, reemplazada por la Scale |
| `2026-11-wifi/` | Cómo funciona el WiFi (estética línea roja) | ✓ terminado (el primero) |
| `2026-11-wifi-hairline/` | Prueba de estética hairline del WiFi | prueba; se unió a `2026-11-wifi/` |
| `2026-11-redes-basicas/` | Switch, router y punto de acceso (Cisco) | solo guion, sin animar |
