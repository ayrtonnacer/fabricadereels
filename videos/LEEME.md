# Videos
Un video = una carpeta = un proyecto HyperFrames. Se crea con `python engine/reel.py nuevo AAAA-MM-tema`. Las salidas (`out/`, `audio/`, `final.mp4`) no se suben: se regeneran con `python engine/reel.py voz` + `render`. Copias livianas de los terminados: `docs/4-referencias/propios/`. Tabla al día: `python engine/reel.py estado`.

| Carpeta | Qué es | Estado |
|---|---|---|
| `_plantilla/` | Punto de partida: ya cumple todas las reglas (portada, gancho, set de 3 estaciones con cámara continua, cierre) | base |
| `2026-11-tokens-1-v2/` | **Qué son los tokens, parte 1 — "la fábrica"**. **El reel de referencia del estilo aprobado**: un set, 5 estaciones, plano secuencia. Nota: es anterior al refactor (su set se llama `fabrica.js` y tiene los tiempos escritos a mano) | hecho (2026-11-16), esperando revisión de Ayrton |
| `2026-11-tensores-scale-oscuro/` | **Qué es un tensor**, primera con estética Scale; escenas separadas (estilo anterior al set único) | ✓ **publicado** en Instagram (2026-11-14); feedback en `docs/1-canal/PUBLICO.md` |
| `2026-11-wifi/` | Cómo funciona el WiFi (estética línea roja, tema viejo) | ✓ terminado (el primero) |
| `2026-11-redes-basicas/` | Switch, router y punto de acceso (Cisco) | solo guion, sin animar |
| `_archivo/` | Versiones reemplazadas y pruebas: tokens v1, tensores línea roja, WiFi hairline, banco de prueba estético (`RESULTADOS.md`). **No copiar de acá** | historia |
