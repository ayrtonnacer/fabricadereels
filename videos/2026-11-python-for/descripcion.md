Un for no escribe mil veces: repite lo mismo para cada elemento de una lista.

Por dentro no cuenta vueltas: le pide a la lista el próximo elemento hasta que no queda ninguno. Por eso range(1_000_000_000) ocupa 48 bytes: los números se crean de a uno.

- Medido en Python 3.13 (sys.getsizeof)
