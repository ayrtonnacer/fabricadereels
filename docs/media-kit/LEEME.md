# Media kit para reels

Prototipo HTML del sistema de diseño de la marca (exportado de Claude Design).
Abrir `Media Kit.dc.html` en el navegador (usa `support.js` e `image-slot.js`).

- `Media Kit.dc.html` — lienzo con las 7 secciones (portada, identidad, reglas, plantillas, animaciones, movimiento y sonido, tokens)
- `Portada.dc.html`, `Objeto.dc.html`, `Demo.dc.html` — componentes que importa
- `marca.css` — tokens de la marca
- `uploads/` — capturas de referencia
